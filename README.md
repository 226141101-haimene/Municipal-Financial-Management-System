Project Description

The Municipal Financial Management System (MFMS) is a C program that helps a municipality manage employees, budgets, suppliers, assets, and reports.

My Role: Budget Management

My responsibility is to develop the Budget Management module.

The module allows users to:

Enter departmental budgets.

Record expenditure.

Calculate the remaining budget.

Check if a department is over budget.

Display budget information.

Validate budget and expenditure amounts.

Budget Calculation

Remaining Budget = Allocated Budget − Expenditure

Example:

Allocated Budget: N$500,000

Expenditure: N$420,000

Remaining Budget: N$80,000

Status: Within Budget

Programming Concepts

My module uses variables, arrays, loops, conditions, and functions to manage budget information and perform calculations.

Team Responsibilities

My assigned responsibility is Budget Management, which includes recording departmental budgets and expenditure, calculating remaining budgets, and identifying departments that exceed their budgets.
